          Network Multiplayer

          Everyone plays on their own PC, on the same Wi-Fi or anywhere online. One player creates a room; the others type its name to join (pick an unusual name: anyone who knows it can join). Dropped out? Join the same room again to get your hero back.

          Connection settings

          Relay server (optional): gets players through any network, for when they can't connect directly (strict Wi-Fi, mobile data, a router that blocks it). Set it up on the host's PC with a free TURN account (for example metered.ca or expressturn.com): paste the server address, or the whole ICE server list from its dashboard.
